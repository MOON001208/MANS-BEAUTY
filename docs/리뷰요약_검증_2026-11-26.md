새 후보는 3101에서 별도로 제공한다. 원격 main과 사용자 루트의 미커밋 변경은 보존했다.

## 변경과 원문 대조

점수·추천·성분·호수 규칙과 프로필 v5/r9는 그대로다. 요약 전용 가드만 보완했다.
SKU/ID 차단 목록을 운영 코드에 만들지 않았다. 실제 AI 호출 없이 규칙 분류와
원문 인용으로 생성하며, 불확실 원문 하나가 있어도 항목 전체를 보류한다.

첫 두 항목은 선택 인용 자체가 잘못됐다는 판정이 아니다. source 분류 또는 승인과
표본 계수가 문제였으며, 기존 점수 정책을 고치거나 문제 source를 삭제하지 않았다.
전언과 병용은 실제 인용에도 있었고 조건을 잘랐다는 주장을 하지 않는다.
해당 동결 입력과 원문은 `tests/fixtures/review_summary_held_samples.json`에 필요한
16건만 author 없이 저장했다. Python 재분류와 실제 공용 resolver → Section SSR에서
항목 전체 보류, 요청 ID·원문 전량 보존, 미검증 극성 배지와 표본 분포 숨김을 검증한다.
기존 경계 fixture에는 새 문제 원문 5건을 추가했다. 직접 사용 정상 대조도 통과한다.

조회 오류와 데이터 부족도 구분했다. 명확한 근거 50건·점수 4·요청 5건에서 2건만
조회되면 unavailable과 `표본 2/5건`, 누락 3건 안내를 표시한다. 0건이면 요청 5건
미확인 안내를 표시한다. 오류가 있으면 `role=alert`가 우선이고 “정보 부족”으로
설명하지 않는다. 부족/보류/오래된 자료에서는 nonzero P/N/M도 숨긴다.

## 최신 자료의 일관성

`python -m pipeline.review_summaries --sync-fallback`으로 두 공개 JSON을 같은
상품·근거 원문 입력에서 생성했다. 상품 공개 필드·프로필과 원문을 두 번 읽고 리뷰
전체 수를 전후 비교했다. 변경되면 결과를 반환하거나 공개 자료를 쓰기 전에 실패한다.
프로필·공개 상품 필드·원문·옵션·행 누락·리뷰 수 변경 회귀를 통과했다.
DB 트랜잭션이 아니므로 이후 갱신은 브라우저의 input_hash·원문 SHA 가드로 보류한다.

- 동일 snapshot ID: `8995141bc5ccdc000f30d3ed8dd815e4853cd6b6409a02e1d0971c3536bf0a4f`
- 읽기 시작: `2026-11-26T07:52:14.178223+00:00`, 확인: `2026-11-26T07:52:56.738493+00:00`
- 87상품·저장 리뷰 35,835건·프로필 rules-ko-v5/r9·DB 쓰기 0건
- 상품별 고유 원문 2,538건, 항목 참조 3,574건, 총 1,254항목(상품 522 + 옵션 732)
- review-summaries.json SHA256: `f4fff1e1bdd6e6738ff51181b3ae8b735c7003d8beae9dba8c329fb950322836`
- catalog-fallback.json SHA256: `1e7b0cbdedcf9cab235f3f4638cfd4ab7240540525a9dbe6cbd90aa98d71d915`

원문·귀속·옵션·SHA·인용 포함 관계와 근거 ID/분모의 전수 대조 위반은 0건이다.
생성 후 공개 API로 다시 읽은 87상품의 input_hash 불일치는 0건이었다.
기준 a42와 비교하면 DB에서 17상품의 프로필 입력이 변경됐다. 변경 시각 및 +33리뷰는
관측 사실이며, 이 변화가 의미 오류의 원인이라는 추정은 하지 않는다.

## 검증과 남은 일

변경 후 전체 `python ops.py verify` 통과: Python·웹 회귀, 396조건 평가, 린트,
정적 빌드, 공개 환경변수·번들 키 검사. 빌드의 두 JSON과 public의 해시는 일치한다.
health/status는 복원 단계에서 통과했고 당시 검사한 production은 아직 기존 main이다.
기존 비동기 가드·옵션 전환·빈 ID 경로는 바꾸지 않았다. 독립 작업자의 18경계 재감사,
새 후보 의미/UI/보안 재검수, 390px·258285 및 실제 배포 후 QA가 남아 있다.

로컬 검사 증거는 `.pipeline-cache/verify-next-summary.log`,
`review-summary-release-audit.json`, `review-summary-source-snapshot.json`,
`review-summary-status-comparison.json`에 있다. 로컬 캐시는 Git에 공유되지 않는다.
실제 사람 평가 응답과 공유 브라우저 저장값은 수정하지 않았다. 실제 사람 평가 0건,
모델 표본 감사이며 전체 정확도를 측정한 결과가 아니다. 구어체·복합 문맥 누락,
표본 편향, 자동 DB 갱신 이후 정적 자료 재배포 전 stale 가능성은 남는다.
