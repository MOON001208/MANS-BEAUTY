어느 추천 목록이 더 잘 맞나요?

설문 조건과 리뷰 근거를 읽고 더 적합한 상위 3개 목록을 골라 주세요. 좌우의 추천 방식 이름은 공개하지 않으며, 점수와 근거는 같은 자료를 보여줍니다. 실제 제품 사용 효과를 판정하는 평가는 아닙니다.

선택 내용은 이 브라우저에 임시 저장됩니다. 평가가 끝나면 응답 파일을 저장해 전달해 주세요. 서버로 자동 전송하지 않습니다.

리뷰에서 확인할 세 가지

  • 고민과 기능 — 모공·잡티가 가려졌는지, 얼마나 유지됐는지처럼 사용 후 경험이 적혀 있는지 봅니다.
  • 표현과 단점 — 화장 티, 마스크·옷에 묻어남, 들뜸을 함께 읽습니다. 도포량·도구 사용법과 제형의 무게감을 구분합니다.
  • 근거의 양과 한계 — 긍정·부정 원문과 근거 수를 함께 봅니다. 정보 부족 항목은 판단을 보류합니다.

상품별 ‘직접 근거 문장 보기’를 펼치면 수집된 리뷰 원문을 읽을 수 있습니다. 목록 선택은 원문을 읽고 판단할 수 있을 때 참여해 주세요.
